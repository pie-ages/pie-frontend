# Divergências

Pontos em que a versão atual do app está parcial, usa dados de exemplo ou difere do que o texto da interface sugere.

| #   | Área                    | O que acontece hoje                                                                                                                                                                                                                                                         | Esperado / observação                                             | Onde                                                                                   |
| --- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 1   | Meu estilo              | Mostra o estilo principal e os secundários de `mockUserIdentifiedStyles`, não o estilo devolvido pelo quiz (`identifiedStyle` do `UserStyleContext` não é lido)                                                                                                             | Exibir o resultado real do quiz                                   | `app/(screens)/MyStyle`, `mocks/styleMocks.ts`                                         |
| 2   | Seleção de estilos      | Opções e seleção inicial vêm de mocks; a seleção não é enviada à API; algumas imagens de fundo são placeholders (`'/'`)                                                                                                                                                     | Usar estilos reais e persistir a escolha                          | `app/(screens)/StyleSelection`, `mocks/styleMocks.ts`                                  |
| 3   | Taxonomias de estilo    | Coexistem três listas: mocks (`classic`, `casual`, `creative`…), `IDENTIFIED_STYLES` (Casual, Elegante, Esportivo, Romântico, Minimalista, Boho) e os estilos da taxonomia da API (filtros da Vitrine). O texto do onboarding cita "Romântico, Criativo, Casual e Clássico" | Unificar a fonte dos estilos                                      | `mocks/`, `types/IdentifiedStyle.ts`, `types/Style.ts`, `constants/OnboardingSteps.ts` |
| 4   | Wishlist                | Fica só em memória: some ao fechar o app ou trocar de conta. A API de wishlist (`/api/wishlist`) existe, mas não é usada                                                                                                                                                    | Integrar com a API de wishlist                                    | `contexts/WishlistContext.tsx`                                                         |
| 5   | Texto da Wishlist       | Estado vazio e onboarding falam em "ícone de prancheta", mas o ícone é um **coração**                                                                                                                                                                                       | Ajustar texto ou ícone                                            | `Wishlist/index.tsx`, `OnboardingSteps.ts`                                             |
| 6   | Editar perfil           | A foto escolhida aparece na tela, mas não é enviada: o `PUT` reenvia o `photoUrl` anterior                                                                                                                                                                                  | Upload da foto ou remover a opção                                 | `EditProfile/index.tsx`, `UseEditProfile.ts`                                           |

## Mockups x app

Diferenças entre os [mockups](mockups/README.md) e a implementação atual. Nem toda diferença é um defeito: em alguns casos o app evoluiu além do mockup.

| Tela              | Mockup                                                           | App                                                                     |
| ----------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Login             | Rótulo "Email"; sem link de recuperação                          | Rótulo "E-mail"; link **Recuperar acesso**; botão mostrar/ocultar senha |
| Quiz              | Cartão com descrição curta e ícone de lupa                       | Cartão só com selo, imagem e nome; ampliação pela prévia ao tocar       |
| Vitrine           | Atalho da Wishlist com ícone de **prancheta**; cards sem coração | Ícone de **coração** no cabeçalho e em cada card (ver item 5)           |
| Vitrine           | Microfone na busca                                               | Microfone só decorativo (sem busca por voz)                             |
| Wishlist          | Sem remover item nem estado indisponível                         | **X** para remover; rótulo "Indisponível"                               |
| Closet            | Sem ação nos cards                                               | **X** para remover peça, com confirmação                                |
| Meus Looks        | Título "Meu Looks"                                               | Título "Meus Looks"                                                     |
| Meus Looks — Foco | Só o carrossel                                                   | Nome, ocasião e paginação abaixo do carrossel                           |
| Meus Looks — Grid | Sempre colagem das peças                                         | Card vira para mostrar a foto do look, quando existe                    |
